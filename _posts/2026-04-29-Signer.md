# Signer — Document Approval Workflow

A full-stack web application that manages document approval workflows inside an organization. Engineers submit requests with PDF attachments and the system automatically routes them up the management chain based on the requested amount. Approvers can annotate, sign, and approve or reject documents directly in the browser.

## Overview

Built to eliminate email-based approval chains, Signer enforces a structured hierarchy with five spending tiers. Each tier requires specific roles to sign off before a request advances, and rejections are automatically notified back to the original submitter with a reason.

## Approval Tiers

| Tier | Amount | Required Approvers |
|------|--------|--------------------|
| 1 | Up to $1,000 | Manager |
| 2 | $1,001 – $5,000 | Manager + Director |
| 3 | $5,001 – $10,000 | Director + VP |
| 4 | $10,001 – $25,000 | VP + CFO |
| 5 | $25,000+ | CFO + Admin |

## Key Features

- **Hierarchical Routing** — amount-based automatic approver selection
- **In-Browser PDF Editor** — annotate, draw signatures, and add text without leaving the app (pdf-lib + pdfjs-dist)
- **Role-Based Access Control** — seven roles with distinct permissions
- **JWT Authentication** — secure stateless sessions with bcryptjs password hashing
- **Admin Panel** — create, edit, delete users and reset passwords
- **Rejection Notifications** — submitters receive explanations on declined requests
- **Docker Support** — containerized with persistent volume options

## Technical Stack

### Frontend
- React 19, React Router v6
- Axios, Tailwind CSS
- pdf-lib, pdfjs-dist

### Backend
- Node.js, Express 5
- SQLite (better-sqlite3)
- JWT, bcryptjs, multer, express-validator
